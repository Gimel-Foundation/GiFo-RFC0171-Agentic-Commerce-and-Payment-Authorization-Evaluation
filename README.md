# GiFo-RFC-0171 (V0.5.1 - Working Draft – Under Review)

Agentic Commerce and Payment Authorization - Evaluation

New Request for Comments of Gimel Foundation (GiFo RFC) - Agentic Commerce and Payment Authorization - Evaluation

Abstract of RFC: Agentic commerce combines several distinct functions: shopping and checkout orchestration, agent recognition, delegated authority, payment authorization and settlement. This RFC evaluates the publicly documented mechanisms that provide those functions, using a common evidence framework.
Scope: The main evaluation selects offerings positioned as agent-commerce or agent-payment solutions and applies the same nine criteria to all of them. As the AP2 protocol (published September 2025) is currently the most present, its evaluation has been detailed as reference case. Additionally, the evaluation framework has been applied to GAuth (July 2025, patent pending) as an inherited authority core together with G-Commerce as commerce enforcement. These refers to GiFo-RFCs 0110, 0111, 0115, 0116, 0117, 0118, 0119 and 0170.
The assessment evaluates architectural mechanisms, not deployment tests, adoption or maturity. The evaluation assesses its named native mechanism and specified dependencies.
Bottom line, AP2 already specifies explicit consent, cryptographic delegation, open-to-closed mandate chains, deterministic constraint checks and cumulative recurring-payment budgets. It does not establish the complete independent authority and lifecycle guarantees (§4). GAuth + G-Commerce has full coverage of all evaluation criteria at the reviewed architectural boundary (§7). The other reviewed architectures establish narrower coverage.
Conclusion: The constructive implication is to combine, rather than conflate, principal authority, platform permission and payment execution. GiFo-RFC 0170 supplies a proposed integration contract and cookbooks.
Traditional payment and checkout interfaces are retained in Appendix D as potential CCPE-F integration substrates, with a complete GiFo-RFC 0170 cookbook crosswalk.
